California's Finest Auto Detail - Complete Website Source

Contents
- index.html: Complete one-page website, with inline JavaScript.
- finishing.css: Visual effects and animation styles.
- sections.css: Extended gallery, care highlights, and map section styles.
- assets/: Five locally bundled automotive stock photographs.

How to use
1. Extract the ZIP, keeping the folder structure intact.
2. Open index.html in a browser to inspect the website.
3. Upload the same files and folders to any static website host.

Notes
- Automotive photographs are illustrative stock images, not documented business projects.
- Google Fonts and the embedded Google Maps view still require internet access.
- Contact buttons use the verified listed telephone number.
- The inquiry form prepares an email draft in the visitor's mail app. It is not a backend booking system.
- Confirm the business's actual services, prices, branding and image license terms before public launch.
